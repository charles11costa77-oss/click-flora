Política de Privacidade — Click&Flora

Última atualização: agosto de 2026

O Click&Flora ("o aplicativo") é desenvolvido pela C's-6. Esta política explica quais dados o aplicativo coleta, como são usados e quais são os direitos do usuário.

1. Dados coletados

O Click&Flora permite tirar ou selecionar uma foto de uma planta para identificação. Essa imagem é:

  • Enviada para a API do PlantNet (serviço de terceiros especializado em identificação de espécies vegetais) apenas no momento da identificação;
  • Não armazenada pelo Click&Flora em nenhum servidor próprio;
  • Não associada a nenhuma conta, nome, e-mail ou identificador pessoal, já que o aplicativo não exige login ou cadastro.

2. Permissões do aplicativo

O aplicativo solicita acesso à câmera e/ou galeria de fotos do dispositivo, exclusivamente para permitir que o usuário fotografe ou selecione a imagem da planta a ser identificada.

3. Compartilhamento com terceiros

A imagem da planta é compartilhada apenas com o serviço PlantNet, responsável pelo reconhecimento da espécie. Consulte a política de privacidade do PlantNet em plantnet.org para mais detalhes sobre o tratamento feito por eles.

O aplicativo pode exibir anúncios por meio do Google AdMob. O AdMob pode coletar identificadores de publicidade do dispositivo para exibição de anúncios personalizados, conforme a política de privacidade do Google, disponível em policies.google.com/privacy.

4. Dados armazenados no dispositivo

O aplicativo pode salvar preferências simples (como idioma) localmente no dispositivo do usuário. Esses dados não saem do aparelho e não são enviados a servidores do Click&Flora.

5. Dados de menores

O Click&Flora não é direcionado especificamente a crianças e não coleta intencionalmente dados pessoais de menores de 13 anos.

6. Segurança

Nenhum dado pessoal identificável é armazenado pelo Click&Flora. As comunicações com a API do PlantNet são feitas via conexão segura (HTTPS).

7. Direitos do usuário

Como o aplicativo não coleta dados pessoais identificáveis nem mantém cadastro de usuários, não há perfil de conta para exclusão. Dúvidas podem ser enviadas para o contato abaixo.

8. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização estará sempre indicada no topo desta página.
